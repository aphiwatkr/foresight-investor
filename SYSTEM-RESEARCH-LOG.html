[2026-10-03] injector idempotency lesson (dashboard stale as-of)

  • A regex injector whose REPLACEMENT changes the format its MATCH expects will pass silently
    forever after the first run (subn → 0, only visible in the n_meta print). Rule: injector
    regexes must match their own output (write the replacement, then re-match IT). The same run
    printed meta:0 — read the counters, they are the smoke alarm.
  • Banner-stamp pattern must be replace-not-prepend; otherwise banners accumulate per run.
  • Public site serves the dashboard at / (index.html); /outlook-dashboard.html 404s.

[2026-10-06] pandas object-bool trap in strategy backtests

  • sig.shift(1).fillna(False) on a bool series yields OBJECT dtype; Python ~True == -2 (bool is an
    int subclass) so (~pos)*cash_ret subtracted 2×cash-return from every invested week — ~5%/decade
    phantom drag across ALL strategies, invisible in Sharpe but visible as "everything underperforms".
    Fix pattern: .shift(1).fillna(False).astype(bool) + np.where(pos, asset_r, cash_r).
  • Second trap same session: metrics assumed 52 periods/yr; monthly variant annualized at 52 → fake
    45% CAGR. Parameterize periods-per-year per frame. Rule: sanity-check every backtest's buy&hold
    leg against the raw price series BEFORE reading any rule's numbers.

[2026-10-29] 100x anatomy + mechanic built — what the data does and does not support | Claude Code session

Built hundredx-anatomy-2026-10-29 + scripts/hundredx_screen.py (+fetch_anatomy_financials.py),
closing the framework's standing offer. Method findings that matter to future builders:
- SEC XBRL companyfacts is the right keyless deep-history source (annual 10-K/20-F facts back to
2006-08; map FY→calendar via the frame CYxxxx tag so January FY-ends land correctly). stockanalysis.com
serves only 5 FY server-side (?p=10Y is client-side only) and its /api/* is Cloudflare-walled to curl.
- Filer quirks that break naive extraction: fp is unreliable (Centrus tags its annual fact fp=Q4 — filter
on the 12-month duration, not fp); revenue moves across tags across eras (RevenueFromContractWithCustomer*
→ Revenues → legacy SalesRevenueNet/ContractsRevenue; IFRS 20-F filers need the ifrs-full namespace);
share counts mix scopes (shares units) and historical splits are unrecoverable → cap-at-base estimates
must be sanity-gated (publish only where base/latest shares within 4x) or left n/f.
- Empirical corrections to the 100x rubric (22 winners ≥20x vs 15 controls): at the trough, winners'
financials are indistinguishable from controls (rev growth 6.2% vs 6.4%; loss rate same; GM lower); the
launch-year inflection is the discriminator (median +17.2%, 16/17 positive); dilution-into-base is normal
reflexive fuel (TSLA +434% shares/2y); GM≥40% is a software-path filter (hardware path 15-25% at base);
the $25M ADV gate would have excluded 6/10 measurable winners at trough → moved to sizing tier.
- Replay honesty: price-only layers have zero edge 2018-2022 (top-15 ≈ base rate); the single full-factor
year-start (2023) hit 8/15 ≥3x vs 17.7% base — n=1, directional only. The screen generates candidates;
the memo pipeline selects. Do not cite the replay as a validated edge.
- Environment: lxml installed into scripts/.venv; _hist/anatomy_sec/ gitignored (raw SEC caches ~100MB).
- Open: microcap-universe extension (<$3B, <10 analysts) still unbuilt; 2023-start replay verdict matures
2026-01→score then; P-call filing on the screen's forward book awaits operator go.
