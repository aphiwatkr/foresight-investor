    syntheses/ (decisions, memos, post-mortems, accountability hubs) · research/

    walk-forward backtest · tournament · rule-based allocator (caps) · snapshot archive
    (scripts/_hist/archive/<date>/ = "what the model believed on date X").

    GitHub Pages.
