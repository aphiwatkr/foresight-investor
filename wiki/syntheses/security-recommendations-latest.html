Methodology

Recommendations are generated by scripts/recommend.py which combines:
1. Sleeve scores (signals.py) — momentum / value / quality / macro-rotation / contrarian / longterm.
2. MDAEM v4 scores (mdaem_v4.py) — 10-dimension quant scoring (5 auto + 5 manual).
3. Backtest portfolio (backtest.py) — current book for hold/trim context.
4. Fundamentals (_instruments.json) — valuation and growth filters.

Action logic: ADD = high conf + T1/MED-HIGH + not in book. START = moderate conf + STARTER+. HOLD = in book + stable signal. TRIM = in book + decaying signal or tier drop. WATCH = interesting but waiting for trigger. REJECT = failed MDAEM gate.
